# CooT recovery runbook (2026-09-03)

Use branch `codex/coot-recovery-v2`. Run every command from the repository
root on a machine that shares the existing `saves/` tree and has a CUDA GPU.
Do not start a downstream stage until every upstream run named below is
finished. The code also enforces this boundary from the exact upstream sweep
IDs, so starting out of order fails immediately instead of consuming stale
files.

All new manifests, response checkpoints, datasets, train checkpoints, and eval
outputs use namespace `reindexed_v3_recovery_20260903`. Existing outputs are
left untouched.

## 1. Population and reusable candidate manifests

These two sweeps are independent and may run at the same time:

```bash
wandb agent cilab-overcooked/overcooked-v3-coot-population/9dk5kefq
wandb agent cilab-overcooked/overcooked-v3-coot-prepare-candidates/96y5boiu
```

Population `9dk5kefq` recreates only the 72 incompatible
`recipe_switch_0` candidates. Prepare sweep `96y5boiu` reads the seven
confirmed-good populations into the new namespace.

## 2. Rebuilt recipe-switch candidate chain

After `9dk5kefq` is fully finished:

```bash
wandb agent cilab-overcooked/overcooked-v3-coot-prepare-candidates/vlucxsjn
```

After `vlucxsjn` is fully finished:

```bash
wandb agent cilab-overcooked/overcooked-v3-coot-response-candidates/u7n37ahg
```

## 3. Score/select and selected HSP responses

After `96y5boiu` and `u7n37ahg` are fully finished:

```bash
wandb agent cilab-overcooked/overcooked-v3-coot-score-select/tukwxox4
```

After `tukwxox4` is fully finished:

```bash
wandb agent cilab-overcooked/overcooked-v3-coot-response/el61vqia
```

## 4. Dataset, CooT training, and evaluation

Run these one stage at a time, waiting for the previous sweep to finish:

```bash
wandb agent cilab-overcooked/overcooked-v3-coot-build-dataset/ftdvzt3r
wandb agent cilab-overcooked/overcooked-v3-coot-train/8mgpw0jd
wandb agent cilab-overcooked/overcooked-v3-coot-eval/14nb93en
```

Expected grid sizes are 8 dataset runs, 48 training runs, and 8 evaluation
runs. Evaluation must never be started before all 48 training runs finish.
