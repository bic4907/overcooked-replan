# split_0 human BC v1

승인된 완주 인간 시연으로 학습한 첫 번째 BC 모델입니다.

| 항목 | 값 |
| --- | --- |
| 원본 데이터 커밋 | `2358ab46f83fd16b5b6bf1b88efd0696d2f46248` |
| 학습 / 검증 | 29판 / 7판 (26,100 / 6,300 agent samples) |
| 시작 위치 | 고정 |
| 네트워크 | 공유 MLP, 256 → 256 → 6, ReLU |
| 최적 epoch / 실행 epoch | 15 / 30 |
| 학습 행동 일치율 | 63.80% |
| 검증 행동 일치율 | 54.97% |
| 검증 non-stay 행동 일치율 | 50.18% |
| 검증 cross entropy | 1.1098 |
| 항상 stay를 선택하는 기준선 | 38.98% |

검증 결과는 보지 않은 판의 정답 행동과 argmax 예측의 일치율입니다. 게임 성공률이나 보상 점수가 아니며, 모델 선택에 사용한 검증셋입니다. 동일 플레이어의 시연이 양쪽 분할에 있을 수 있으므로 새로운 플레이어에 대한 일반화 측정도 아닙니다. 게임 rollout 및 cross-play 평가는 수행하지 않았습니다.

- `policy.msgpack`: 최적 모델의 Flax 파라미터
- `normalization.npz`: 학습 관측에서 계산한 채널별 평균과 스케일
- `config.json`: 네트워크, 환경, 학습 설정 및 라이브러리 버전
- `dataset.json`: 원본 파일 SHA-256, 시연 메타데이터, 판 단위 분할
- `metrics.json`: 학습 결과, 검증 혼동행렬 및 epoch별 기록
