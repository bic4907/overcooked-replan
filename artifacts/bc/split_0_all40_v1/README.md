# split_0 BC — all 40 recordings

사용자 요청에 따라 40개 원본 전부를 사용했습니다. 승인·완주 36개, 미승인 완주 2개, 거절 완주 1개, 승인 중도 종료 1개(442스텝)를 포함합니다. 원본 상태는 변경하지 않았습니다.

- 17,992 환경 스텝 / 35,984 에이전트 행동.
- 두 에이전트 공유 MLP(256×2), seed 0, 15 epoch 고정 학습.
- 기존 모델의 검증에서 선택한 epoch 수를 사용했습니다. 새 모델은 미사용 검증셋이 없으며 학습 행동 일치율 63.50%는 일반화 성능이 아닙니다.
- 기존 체크포인트를 덮어쓰지 않고 별도로 저장했습니다.

## BC self-play, 50 episodes

두 모델 모두 `split_0`, 고정 시작 위치, 판당 450스텝, 샘플링 시드 0~49, categorical 행동 선택을 사용했습니다. 팀 공유 보상은 한 번만 합산합니다.

| 항목 | 기존 모델 (29판 학습) | 전체 40개 학습 |
| --- | ---: | ---: |
| 평균 점수 | 24.4 | 29.2 |
| 표본 표준편차 | 23.31 | 26.56 |
| 중앙값 | 20 | 20 |
| 최저 / 최고 | 0 / 80 | 0 / 120 |
| 0점 판수 | 17 / 50 | 13 / 50 |
| 1구간 평균 | 12.4 | 14.4 |
| 2구간 평균 | 2.0 | 3.2 |
| 3구간 평균 | 10.0 | 11.6 |

같은 50개 시드에서 관측된 평균은 4.8점 높아졌습니다. 한 학습 시드의 모델 비교이며, 학습 데이터 수와 포함 상태도 함께 바뀌었으므로 어떤 변경이 효과를 냈는지 분리해서 말할 수 없습니다. 특히 2구간 점수는 여전히 낮습니다.

`selfplay_50.json`은 판별 점수, 구간 점수, 설정과 체크포인트 SHA-256을 포함합니다. `dataset.json`은 실제 사용한 40개 원본의 메타데이터와 해시를 기록합니다. `config.json`, `metrics.json`, `normalization.npz`, `policy.msgpack`은 학습 설정, 학습 기록, 정규화 통계와 가중치입니다.
